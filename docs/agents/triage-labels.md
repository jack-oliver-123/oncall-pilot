# Triage labels

Matt Pocock skills 使用五个 canonical triage role。本仓库将它们映射为同名的 GitHub label。

| Matt Pocock skill role | 本仓库的 label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 issue |
| `needs-info` | `needs-info` | 等待 reporter 补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

如果 skill 使用 role 名称，请使用右侧对应的 label 字符串。
